# Our principles
- **Your data stays local.** Software should run on your hardware and store data in your filesystem whenever the job does not genuinely require a server.
- **Pay once, keep it.** A licence should not expire, and software you bought should not stop working because a subscription or licence server did.
- **Leaving stays easy.** Open formats and exportable data matter. Lock-in is a design decision; we choose the other one.

No ads. No business model built on your data. No account where one is not needed.
